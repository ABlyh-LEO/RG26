## 本机浏览器环境说明

本次 Windows 执行环境中的 Playwright Chromium 会取消 Blob 下载；在独立 `about:blank` 页面下载最小 JSON 也可复现，不能据此断言用户正常安装的 Chrome 无法导出。该环境的交接用例仍检查真实下载事件、文件名和导出的完整 Blob 内容，再将这些字节送入实际文件导入控件验证恢复。只有 Windows Chromium 且返回 `canceled` 时允许此适配，并记录测试注解；其他环境必须成功保存实际下载文件。WebKit 已完成实际 `download.saveAs`、再导入和未完成输入恢复。

本机 WebKit 初始化需要等待真实源文件、草稿和 Git 检查，因此初始化就绪断言使用 15 秒上限；录分、预览与上线结果断言保持具体业务条件，不依赖固定延时。
