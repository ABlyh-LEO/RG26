# 2026-10-03 部署门禁假红修复（真实数据不再卡部署）

## 现象

录入第 1、2 场排位赛成绩并推送后，CI 与 Pages 部署都在同一条用例上失败：

```
tests/e2e/app.spec.ts:87
  await expect(page.getByText('正式排名', { exact: true })).toBeVisible();
Error: element(s) not found        （desktop/mobile/tablet-chromium 与 mobile-webkit 四个项目全挂）
```

**后果**：部署被挡住 → 你刚录入的两场成绩没有发布到观众端（CI 红、Pages 仍是旧快照）。

## 根因

这些用例读取的是**正式数据**（正式构建产物），而断言写的是**赛前状态**：

| 用例 | 断言 | 为什么会在录入成绩后失效 |
| --- | --- | --- |
| `app.spec.ts` 13.2-2 | 必须有「正式排名」 | 排位赛排名卡是三态：无成绩时标题为「正式排名」（占位）、有已确认成绩但未定榜时为「当前排行」（实时·未确认）、定榜后才是「正式排名」。录入第一场成绩后标题就变成了「当前排行」 |
| `app.spec.ts` 13.2-2g | 正文必须含「到达最终分」 | 这句话只在**尚无成绩**时以占位文案「到达最终分时间待确认」出现；有成绩时显示的是实际「N 秒」 |
| `app.spec.ts` 13.4 紧凑性 | 画布高度 `< 1600` | 瑞士轮画布装着 33 场比赛：无成绩 1203px，全部成绩 2267px（卡片变高）。固定上限在赛季推进中必然被突破 |

第一处与第二处会在**录入第一条成绩**时立即爆；第三处会在**瑞士轮打完**时爆。

## 修复

断言改为**与数据状态无关**，同时保留原有检查意图：

1. 排名卡：断言「正式排名」或「当前排行」**之一**存在；当它是「当前排行」时，必须明确标注
   「实时 · 未确认」「未确认，不作为晋级依据」（这正是当初定下的口径）。
2. BO3 时间口径：断言正文匹配 `到达最终分|N 秒` —— 要么说明口径，要么给出实际时间。
3. 画布紧凑性：把「固定高度上限」换成真正的不变量——**画布高度跟随自身最高列内容**
   （`height - bodyMax < 80`），另留 `< 4000` 的防失控界；同时保留"同一行、列从左到右递增"。
   「短分区不继承最长列高度」由相邻用例继续守住。

## 验证方式（重要：这次用了"状态无关性压力测试"）

用 `npm run snapshot:full-season` 生成**赛季末快照**（44/44 跑图、33/33 瑞士轮、14 场决赛、冠军已产生），
把它临时替换为公开快照后跑完整套 e2e——这样能一次暴露所有"只在某种数据状态下成立"的断言：

```powershell
npm run snapshot:full-season                 # 生成 tmp-full-season.json
Copy-Item tmp-full-season.json public\data\event.json -Force
npx playwright test                          # 赛季末状态
git checkout HEAD -- public/data/event.json  # 还原正式数据
```

| 数据状态 | 结果 |
| --- | --- |
| 赛前（0 条成绩） | ✅ 372/372 |
| 当前正式数据（2 条成绩） | ✅ **372/372** |
| 赛季末（全部成绩） | ✅ **372/372** |

压力测试在修复前精确抓到 2 处（`13.2-2g`、`13.4 紧凑性`），修复后两态全绿；
用例清单用 `npx playwright test --list` 逐项比对，三种状态下**完全一致**（覆盖率不随数据变化）。

另外顺带确认：`data/event.json` 与 `public/data/event.json` 都已包含这两场成绩，无需重新录入。

## 教训（写给下一个赛季）

- 读**正式数据**的 e2e 只能断言"任何数据状态下都成立"的结构性事实；涉及"赛前才有"的文案、
  计数、上限时，应注入固定数据（`usePreEventSnapshot` / `page.route`），或写成状态无关的断言。
- 数据驱动的绝对阈值（高度、条数、时长）几乎注定在赛季推进中失效；改成"相对自身内容"的不变量。
- 新增或修改这类用例后，至少跑一次**赛季末快照**的完整 e2e。
