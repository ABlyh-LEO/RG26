## 2 瑞士轮（重点）

### 2.1 配对——**不符合，已修正**

| | 手册原文 | 修正前实现 | 修正后 |
| --- | --- | --- | --- |
| R1 | 「第一轮按排位赛名次**分为前后两半**，依次安排**第1名对第9名**、第2名对第10名，直至第8名对第16名」（`schedule-extracted.md:49`） | 首尾：1v16、2v15 …… 8v9（旧 `swiss.ts` R1 分支） | 1v9、2v10 …… 8v16（`src/domain/swiss.ts:147-158`） |
| R2 起 | 「按**第1名对末名、第2名对倒数第2名首尾配对**」；附一简例「甲对辛、乙对庚、丙对己、丁对戊」，并给出「六队组为第1名对第6名…四队组为第1名对第4名」（`:49`、`:157`） | 组内相邻：1v2、3v4 …… | 组内首尾（`src/domain/swiss.ts:192-201`） |

**影响面**：配对直接决定每场的对手 → 影响对手强度 O → 影响综合分 R → 影响组内名次 → 影响八强种子与双败对阵。修正前若据此生成并公布对阵，整条链路都会错。

**数据影响**：正式源与公开快照的 R1 槽位仍是 `pending`（尚未公布），**没有已公布的错误对阵需要撤回**；修正后由维护者重新生成即可。

**防回归**：`tests/domain/swiss-manual.test.ts`（8 项）不写死队伍编号，而是先取该组在 `standings` 中的排序，再断言「第 k 场 = 第 k 名对第 (n−1−k) 名」，并单独断言 R1 的 1v9…8v16、常规赛程 33 场与 2/3/3/3/3/2 分布。

### 2.3 晋级、淘汰与停止参赛——符合

手册（赛段二）：「累计三胜晋级八强，累计三败淘汰（结算十六强）；达到三胜或三败后停止参赛」。
实现：`determineActiveTeams`（`swiss.ts:230-239`）排除 `wins>=3 || losses>=3`，但**保留其 P/W/L**，且 O/R 随历史对手更新（与附一第三节「已晋级、已淘汰队伍的胜率和 P 按实际已赛成绩保留，其 O 随历史对手成绩更新」一致——每轮 `calculateSwissStandings` 重算全体）。

### 2.4 组内排序——符合

手册（附一四）：「同战绩组依次比较 **R 高者、P 高者、T 小者、排位赛名次靠前者**；前项相同才比较后项。按原始精度排序，公布时保留两位小数。」
实现：`sortGroupEntries`（`standings.ts:194-207`）顺序完全一致，且用有理数比较（`cmp`）保证"按原始精度"，展示才两位小数；排位名次缺失者排在有名次者之后而非当作 0/最后一名（`compareQualificationRank`，`standings.ts:213-218`）。

### 2.5 评分公式——符合

| 手册（附一） | 实现（`src/domain/scores.ts`） |
| --- | --- |
| `A = (100/n) Σ min(s_k,16)/16` | `contributionA`（`:240-244`）：先 `clamp(s,0,16)/16` 求和，再乘 `100/n` |
| `B = (1/n) Σ (50 + 5·clamp(d_k,−10,+10))` | `contributionB`（`:247-256`），截断常量 `DIFF_CLAMP_*`（`:43-44`） |
| `P = (A+B)/2`；`n=0` 时 A/B/P 记 0 | `:308`（`n === 0 ? ZERO : (a+b)/2`） |
| `v_j = W_j/(W_j+L_j)`；无胜负记录记 0 | `:309-310` |
| `q_j = 50·v_j + 0.5·P_j` | `:348-352` |
| `O = (1/m) Σ q_j`，**按每场对应对手计入一次、不去重** | `:341-356`（`team.opponents` 不去重） |
| `R = 0.6·P + 0.4·O` | `:355`（`THREE_FIFTHS`/`TWO_FIFTHS`） |
| `m=0` 时 O 记 0，`R = 0.6P` | `:343-346` |

有理数实现见 `rational.ts`：0.6/0.4/0.5 → 3/5、2/5、1/2（与初版计划一致），避免浮点误差影响排序。

### 2.6 统计集合拆分——符合

手册（附一六）：「未开赛的弃权局及行政判负中止场次，**双方均不计入 A、B、P、T**，胜负及已登记对阵仍计入战绩和 O」「n=0 时…T 记 360 秒」「无胜负记录时 v 记 0」「m=0 时 O 记 0」。
实现：`countsTowardPerformance`（`scores.ts:31-33`，仅 `normal`/`early-end`）与 `countsTowardRecord`（`:36-38`，恒真）严格分离；`computeTeamScores` 里 `m/W/L/opponents` 对所有已结算场次累加、`n/s/o/t` 仅对有效比赛累加（`:283-298`）。

### 2.7 零分与缺失值——符合

- 零分局时间：`resolveSeconds`（`scores.ts:95-103`）强制 360 秒；写入端 `normalizeSeconds`（`operator/draft.ts`）同样按零分补 360。
- **缺分不补 0**：`parseScore`（`:74-86`）失败即记 issue，绝不当 0；缺失时间只告警不伪造（`:104-111`）。
- 超过 360 秒只提示复核，不擅自定义判罚（`:112-117`）。

### 2.8 重赛——符合

手册（附一一）：「重赛只取最终有效场次」。
实现：`collectSettledMatches`（`scores.ts:122-142`）只认 `effectiveAttemptId` 且 `resultStatus==='confirmed'` 的那一次；工作台"重赛"以新 attempt 追加并保留 `supersedesId`（`operator/result-edit.ts`）。

### 2.9 八强种子与双败对阵——符合

| 手册 | 实现 |
| --- | --- |
| 「八强中 3-0 组为第 1、2 名，3-1 组为第 3 至 5 名，3-2 组为第 6 至 8 名」（附一四） | `publishFinalsSeeding`（`operator/draft.ts:873-905`）：W1/W2 取 3-0 前两名；W3/W4/L1 取 3-1；L2/L3/L4 取 3-2；组内顺序用同一排序口径 |
| 上午首轮 1v5、2v6、3v7、4v8（附二） | `FINALS_NODES`（`finals.ts:40-51`）+ 数据校验（`data/event.json` F-M1…F-M4） |
| 下午胜者组 W1vW4、W2vW3；败者组首轮 L1vL4、L2vL3；败者组第二轮 W1/W4 负者 vs L2/L3 胜者…（附一四） | `finals.ts` 的 slots 依赖图 + `validateFinalsGraph` |
| 「胜败流转固定，不套用通用双败模板」「没有总决赛重置」 | 固定 14 场节点表；`F-GF` 单组 BO3 |

### 2.10 名次结算——符合

手册（附一四 + 名次结算表）：「F-L1A/L1B 及 F-L2A/L2B 败者 → 八强；F-LSF 败者 → 四强；F-QUAL 败者 → 季军；F-GF 败者/胜者 → 亚军/冠军；排位赛 17–22 → 优秀奖；瑞士轮淘汰者 → 十六强」。
