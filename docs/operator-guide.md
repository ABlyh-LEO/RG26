# 维护者操作手册（旧链接入口）

完整且持续维护的手册已统一到 **[OPERATOR_GUIDE.md](OPERATOR_GUIDE.md)**。本页仅保留旧链接，避免出现两份步骤不同的手册。

当前日常流程：双击 `start-operator.cmd` → 赛事工作台录入 → 保存并确认结果 → 预览与发布 → 核对累计变更 → 生成观众预览 → 确认发布 → 等待“观众已可见”。JSON 导出用于备份和交接。

## 1 启动与交接

见[启动、升级与入口](OPERATOR_GUIDE.md#startup)及[备份交接](OPERATOR_GUIDE.md#handover)。维护地址是 `http://127.0.0.1:5199/operator.html`。
